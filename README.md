# allis-reference-node

An open, community-governed AI reference node for grounded local knowledge, privacy-aware continuity, auditable orchestration, and reproducible civic infrastructure.

Allis is an open reference implementation for locally governed AI infrastructure. It is designed to help communities, nonprofits, public institutions, researchers, and future stewards build systems that are inspectable, privacy-conscious, auditable, and locally accountable.

This repository is not the official production infrastructure of Harmony for Hope, MountainShares, or any partner organization. It contains no production secrets, private user data, private continuity records, KYC materials, operational credentials, or live infrastructure controls.
